# Praktikum Pemrograman Berorientasi Objek (OOP)

Kumpulan kode program Java untuk memenuhi tugas Praktikum Pra UTS Pemrograman OOP.

## Daftar Isi Praktikum
- **Praktik 1-2**: Dasar Class dan Object (Motor)
- **Praktik 3**: Class Beraksi (Sepeda)
- **Praktik 4**: Enkapsulasi (Mobil Baru)
- **Praktik 5**: Atribut dan Method (Mahasiswa & SKS)
- **Praktik 6**: **Inheritance** (Pewarisan) - Orang, Mahasiswa, Dosen
- **Praktik 7**: **Polymorphism** - Hewan & HewanPolimor
- **Tugas 1**: Implementasi Database Java Dasar

## Cara Menjalankan
Gunakan perintah berikut di terminal pada setiap folder:
1. Compile: `javac *.java`
2. Run: `java [NamaFileUtama]`
